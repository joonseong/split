# 제품 콘셉트: MinimalReadingApp

## 한 줄 요약

긴 책을 부담 없이 끝까지 읽게 만드는, **절제된 분량의 독서 습관 앱**.

## 문제

- 사람들은 책을 사두고도 분량에 압도되어 첫 장을 넘기지 못한다.
- "오늘은 50페이지" 같은 목표는 쉽게 무너지고 죄책감만 남는다.

## 해결

책을 아주 작은 단위로 쪼개고, 하루에 읽을 수 있는 양을 **일부러 제한**한다.

| 단위 | 크기 | 설명 |
| --- | --- | --- |
| 페이지(Page) | 약 220자 | 모바일 한 화면에 부담 없이 읽히는 분량 |
| 시리즈(Series, 한 화) | 10페이지 | 약 2,200자. 한 번에 읽는 묶음 |
| 일일 한도 | 3시리즈 | 하루에 더 읽고 싶어도 멈추게 하는 절제 장치 |

> 더 읽고 싶은 마음을 남겨 두는 것이 핵심이다. 내일 다시 앱을 열 이유가 된다.

## 핵심 흐름

1. **서재** — 읽을 수 있는 책 목록과 "오늘 남은 시리즈" 표시
2. **시리즈 목록** — 한 화씩 나열. 일일 한도를 넘기면 잠금 표시
3. **리더** — 페이지를 한 장씩 넘기며 읽고, 진도는 자동 저장

## 분할 규칙 변경

모든 수치는 `ios/MinimalReadingApp/Models/ReadingConfig.swift` 한 곳에서
바꾼다. 값을 바꾸면 페이지·시리즈·일일 한도가 앱 전체에 일관되게 반영된다.

## 향후 과제

- 실제 콘텐츠 백엔드 연동 (현재는 번들 텍스트 샘플)
- EPUB/PDF 업로드 → 서버 분할 (기존 Flask 프로토타입의 역할)
- 읽기 streak, 리마인더 알림
- Android(Kotlin) 앱에서 동일 규칙 재현
